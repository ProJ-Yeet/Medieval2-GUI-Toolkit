# beta 2026-09-06b

The second beta cut today. It is **everything in v2.2.1 with the campaign map
switched on**, so if you have read the v2.2.1 notes you have read most of this
one: the duplicate-entry cleanup, HD textures in the 3D viewer, the reorganised
repository and the README's screenshots are all here too.

Named `2026-09-06b` because `beta 2026-09-06` was cut this morning and is still
published. Betas are named by the day they were cut; two in a day get a letter.

This is still a **beta** for the reason the first one was: the campaign map
editor is the first thing this toolkit does that WRITES to a campaign, and a
campaign is the one part of a mod where a bad write shows up ten turns in rather
than the moment you load it. Everything it writes is backed up and one Undo
away. Read the plan before you press Apply.

## New since beta 2026-09-06

* **The entries your modeldb lists twice, and the two ways out.**
  `battle_models.modeldb` is a flat stream of entry blocks and nothing stops the
  same name appearing twice. Third Age Reforged ships eight such names, Divide
  and Conquer five. **M2TW reads the first block with a name and walks past
  every later one**, so a later block is a model the mod is carrying and cannot
  reach, with no error anywhere saying so.

  BMDB mode has a **Duplicates** button now. Per block that is not the first of
  its name: **Rename** it, so it becomes an entry a unit can be pointed at, or
  **Remove** it. Which is right depends on whether the block is a copy of the
  first or a different model, so that is the loudest thing on each row - an
  exact copy says so and costs nothing to drop, and a different one is listed
  field by field ("skins for 5 factions vs 3 (adds england, russia)") with the
  line number of each block. The first block of a name is never touched by
  either: it is the one the game reads. Only the modeldb is written, backed up
  first, undoable from 🕑 Log.

* **HD textures in the 3D viewer.** The viewer halves any skin over 1024 pixels,
  which is right when the question is "which model is this" and wrong when it is
  "is that seam actually painted". There is a **HD textures** button next to
  Wireframe now: it draws the sheet at the size the mod ships it, which is the
  size the game draws. Remembered between sessions, reloads only the skins, and
  both sizes are cached separately so switching back and forth converts each
  sheet once.

* **The repository is laid out so you can find things in it.** Only
  `Install-Dependencies.bat`, `Launch-Medieval2-GUI-Toolkit.bat` and
  `README.md` are at the top; everything else is under `main/`. The developer
  scripts that used to ride along inside `tools/` and ship in every zip are
  under `main/dev/`, grouped by what they do, and no longer ship. **If you are
  running from a download this changes nothing for you.**

* **The README shows the tool**: ten screenshots of the real thing, one per
  major screen, generated by a script so they cannot go a version out of date.
  The install order is stated properly too - `Install-Dependencies.bat` first,
  then the launcher - and the credits are in it.

* **Three test suites that were never runnable on their own** now are.

## The campaign map, unchanged from beta 2026-09-06

Ten TGA layers, `descr_regions.txt` and `descr_strat.txt` on one screen: paint a
province and every file that names it follows, drag a general onto a tile, place
a settlement, and check the whole map against what the engine will accept before
the game ever sees it. See `RELEASE_BETA_2026_09_06.md` for the full account of
what it reads and what it writes.

## Known limits of this beta

Unchanged from beta 2026-09-06:

* Forts, watchtowers and resources are **read and drawn, not placed**.
* The terrain render is flat colour, not textured.
* Deleting a region and creating a campaign from scratch are not in this build.
* Nine lines of Divide and Conquer's `descr_strat.txt` do not parse, and all
  nine are the mod's own defects. They are read as far as they can be, kept, and
  reported by line number rather than silently dropped.
