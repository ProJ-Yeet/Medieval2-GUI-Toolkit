# beta 2026-10-01

**Everything in v2.4.2 with the campaign map switched on**: the interface in
German, offered as a draft in Settings, including every panel of the campaign
map editor, and the two Unit Transfer fixes (a reroute that lands files in
the folder picked, and a dictionary name the destination already uses caught
as a conflict).

Nothing on the map itself changed since beta 2026-09-30.

This is still a **beta** for the reason the first one was: the campaign map
editor is the first thing this toolkit does that WRITES to a campaign, and a
campaign is the one part of a mod where a bad write shows up ten turns in rather
than the moment you load it. Everything it writes is backed up and one Undo
away. Read the plan before you press Apply.
